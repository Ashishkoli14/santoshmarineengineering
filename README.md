## 🚀 Quick Start (For Developers)

### Prerequisites
- Web browser (any modern browser works)
- Text editor (VS Code, Notepad++, etc.) for modifications

### Running Locally
1. Download or clone this repository
2. Open `index.html` in a web browser
3. Website loads instantly — no build process needed

### Modifying Content
1. Edit `index.html` in any text editor
2. Update company info, services, contact details
3. Save file
4. Refresh browser to see changes

### Deploying Updates
1. Edit `index.html` locally
2. Drag updated folder to **https://app.netlify.com**
3. Site auto-updates in **30 seconds**
